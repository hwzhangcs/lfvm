# 验收测试对照（SRS V2.1 附件 C、表 8-5）

本表把 SRS 中的每条验收条件、异常测试和非功能需求对应到**自动化测试**或**界面手工步骤**。

- 自动化测试位于 `crates/lfvm-core/src`，写作“文件::测试名”，运行：`cargo test -p lfvm-core`。
- 前端测试位于 `apps/desktop/src`，运行：`cd apps/desktop && pnpm test`。
- 标“手工”的项目需要在桌面程序中操作并截图；验收平台为 Windows 10、Windows 11（x64）。
- 测试记录须写明软件构建号、测试平台、输入、步骤、预期结果、实际结果及截图或日志（附件 C.1）。
